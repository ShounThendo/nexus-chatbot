The hosted website does not run your laptop’s Python process or local Ollama model. Its own compatible server handles the core features. The two reminder databases are separate.

Run the full hybrid bot on Windows

  1. Download and extract the ZIP.
  2. Open the python folder in VS Code and open its terminal.
  3. Run the commands below, with Ollama started on your laptop.
  4. Open http://127.0.0.1:8000 and keep the terminal open.
py -m pip install -r requirements.txt
ollama pull qwen3:1.7b
py server.py

For the terminal-only bot, use py main.py. Its reset command clears recent conversation context; quit exits.

How a message becomes an answer

1. Input & intentThe page gets your message. NLP identifies the action and extracts details.
2. DispatcherThe dialogue manager chooses reminders, knowledge, external APIs, or generative AI.
3. Action or lookupRules edit reminders. Retrieval searches saved knowledge. APIs return external data. Python uses Ollama for ordinary conversation.
4. Reply & recent contextThe answer is displayed. Python remembers up to four recent question/answer pairs.

Guest reminders stay in that browser. Sign in on the public website to save reminders to your account. Alerts work while the page is open, with no push alerts when closed.

Weather uses Open-Meteo. Exercise search uses the public-domain free-exercise-db JSON catalogue. These are general exercise references, not fitness tracking or personalised coaching.
